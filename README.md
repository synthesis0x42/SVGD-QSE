This project aims to improve the accuracy and efficiency of quantum state estimation for quantum computing. Currently, Bayesian mean estimation (BME) is a highly accurate method but is computationally complex. We propose using Stein Variational Gradient Descent (SVGD) as an alternative to BME for quantum tomography. SVGD is a general-purpose variational inference algorithm that approximates the true posterior distribution using particles. By minimizing the Kullback-Leibler divergence, SVGD can produce a more accurate estimate of the quantum state. Our project will consist of a theoretical review of SVGD and related concepts such as measure theory and reproducing kernel Hilbert spaces, as well as a numerical simulation using Python libraries such as PyMC3. 

_Task: produce a faster, more robust, and more reliable method of quantum state estimation for quantum computing._
